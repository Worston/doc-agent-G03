# Per-stage design choices (A2 deliverable)

*Corpus: The Home-Keeping Book (Brown, 1918), Internet Archive `homekeepingbook00brow`.
Domain: Historical Cookbook / Culinary Heritage. Primary NFR: Calibrated (ECE ≤ 0.05).
Data speciality: Multi-column reading order (secondary: degraded/dirty scans).*

*All measurements are from the 40-page human-verified held-out slice (`grading_kit/heldout_pages/` + `labels.jsonl`), seed 42, never trained or tuned on.*

---

| Stage | Problem statement | Data | Model / Algorithm | Methods | Design decisions | Development | Deployment | MLOps |
|---|---|---|---|---|---|---|---|---|
| **0 Frame** | Build a grounded QA agent for early-20c household manuals. User: food historian / heritage-cookery researcher. Success metric: groundedness ≥ 0.90. | 624 scanned pages (300 DPI grayscale PNG), public domain (Internet Archive). Corpus floors: ≥ 300 pages  (506 content), ≥ 60k words  (318,259). | — (framing stage only) | Section-level train/val/test split (never page-level). Held-out 40 pages for OCR oracle, stratified by layout type at corpus share. Exclude contents/index pages from held-out (cannot author real questions from them). | Domain uniqueness: one corpus per group. Leakage prevented by assigning whole book sections to exactly one split. `configs/task.yaml` is the single source of all thresholds. | `configs/task.yaml`, `grading_kit/manifest.yaml`, `data/provenance.md`. EDA re-derives every A1 number from source PDF so nothing rests on an unverifiable claim. | Corpus on Internet Archive (public domain). 624 PNGs in `data/raw/`. `scripts/get_data.sh` fetches and renders. | `data/versioning.py::snapshot()` records SHA-256 of all corpus files at build time. |
| **1 Ingest + Preprocess** | Remove skew, noise and illumination drift from 1918 letterpress scans so OCR sees clean input. Secondary speciality E1 (degraded scans). | 624 grayscale PNGs. Measured degradations: page-wide skew (median 0.12°, max 0.55°), paper speckle, ink bleed-through, gutter shadow. | Classical OpenCV pipeline: profile-score deskew → median filter → (optional) Sauvola/Otsu binarize → despeckle. | Deskew: coarse-to-fine profile-score sweep on a downscaled Otsu mask. Denoise: median ksize 3 (vs Gaussian which softens stroke edges). Binarize: **off** by default — Tesseract already binarizes internally, and TrOCR needs continuous tone. | Off-by-default binarize: Sauvola (0.0911 CER) and Otsu (0.0799) both worse than deskew+median alone (0.0797). Deskew alone barely moves CER because the IA scanner already deskews. Error is concentrated on reading-order failures, not pixel quality → this motivated Stage 2. | Parallel via `ProcessPoolExecutor`; serial fallback for notebooks (BrokenProcessPool). Config fingerprint written to `data/interim/params.json`; re-runs are cached. | `data/interim/<page_id>.png` (gitignored, re-derivable). Preprocessing flag in `config.yaml preprocess.enabled`. | Cache-on-disk: only pages older than their source are reprocessed. |
| **2 Layout** | Detect multi-column structure and emit regions in reading order. Primary speciality E2. | Ink-projection profiles of preprocessed 300 DPI pages. 33% of content pages are two-column with a 25–98 px gutter. | **Recursive XY-cut** on ink projections (`vision/layout.py`). No learned detector (layoutparser/detectron2 not installable on Apple Silicon). | Column cuts fire first (widest full-height gutter gap ≥ 2.5% page width). Row cuts fire on gaps exceeding `row_gap_factor × local_leading`. Leaf classification: text / heading / table / figure from geometry + ink statistics. `_body()` strips a 1.5% border to remove scan-edge artefacts. | Widest-gap rule for row cuts (vs topmost-gap): topmost fixes p138 but costs 0.0272 → 0.0490 CER overall. Known limitation: non-Manhattan layouts degrade to one full-page region. Column-structure accuracy: **33/40** vs 15/40 for the A1 centre-crossing heuristic. | Mixed-layout CER drops from **0.163 → 0.026** (3× improvement) after segmentation. Single/two-column pages have a small cost (recogniser loses page-wide context). | Stateless per-page: works on any preprocessed PNG. No learnt weights → no model file to ship. | Per-stage unit test in `tests/test_ingest.py`. |
| **3 OCR** | Transcribe each layout region to text. | Layout regions (bbox + kind) from Stage 2 in `data/interim/` coordinate frame. 40-page oracle: 26,397 reference words. | **Tesseract 5, --psm 6** (uniform text block). TrOCR-small fine-tuned available but not used in production — see score table. | Tesseract: given the region crop whole; handles its own line segmentation and binarization. TrOCR: line-box splitter required (band-merging on horizontal ink valleys) because TrOCR is a line recogniser. Fine-tune distilled on IA ABBYY text layer (noisy teacher, CER ~0.048/line). Exclude test pages and 40 oracle pages from fine-tune data. | Tesseract chosen: CER **0.0272** vs TrOCR-small 0.8545, TrOCR-small-finetuned 0.6971, TrOCR-base 0.8104. Gap is structural (on same line crops: Tesseract 0.0068 vs TrOCR-small 0.62). Speed: Tesseract 2.8 s/page vs TrOCR-small 19.6 s/page on CPU. | `finetune: true` in config activates fine-tuned weights when available in `models/trocr-hkb/`; falls back to base model with a warning if not built. Figure regions skipped (`skip_kinds: [figure]`). | Tesseract installed system-wide; no GPU required for production. TrOCR fine-tune optional bonus. | `configs/ocr_train`: `base_model`, `epochs`, `lr`, `batch_size` all in config. Training via `training/lit_modules.py`. |
| **4 Index** | Chunk, embed and store the OCR'd text for dense retrieval. | ~4,000 raw region chunks from Stage 3 (median 47 tokens; 39/96 tested chunks are under 32 tokens). | Chunker: sliding word-boundary window, wordpiece-counted. Embedder: `sentence-transformers/all-MiniLM-L6-v2` (384-dim, L2-normalised). Store: `numpy:flat` exact inner-product search. | Window size: **256 wordpieces** (not words) — this corpus runs 1.32 pieces/word so a 256-word window would be ~338 pieces and exceed MiniLM's limit. Overlap: 32 pieces. Vectors L2-normalised so inner product ≡ cosine, bounded in [−1,1] for a meaningful `weak_threshold`. | FAISS flat and HNSW conflict with torch's `libomp` on macOS (OMP Error #15 → SIGSEGV). numpy:flat: 0.004 ms/query vs FAISS flat 0.009 at recall@10 = 1.000 for all three on ~1,800 vectors. HNSW pays off in millions; this book is ~1,800 windows. | `build_knowledge_base()` in `pipeline.py` runs Stages 1–4 in one process. Cross-encoder reranker (`cross-encoder/ms-marco-MiniLM-L6-v2`) wired at Stage 5. `meta.json` stores embedder name; `load()` refuses an index built with a different model. | `data/index/{vectors.npy, chunks.jsonl, meta.json}` (gitignored). `scripts/build_index.sh` one-command rebuild. | `meta.json` records `embed_model`, `dim`, `count`, `type`. Rebuild triggered automatically when metadata disagrees with config. |
| **5 Retrieval** | Return the top-k chunks most relevant to a query. | Embedded query (same MiniLM encoder as Stage 4b). `weak_threshold = 0.35`. | `Retriever` (dense) + optional cross-encoder rerank (`cross-encoder/ms-marco-MiniLM-L6-v2`). | Query embedded via `encode_texts` (same path as passage embedding). Inner-product search on `VectorStore`. Reranker applied if `retrieve.rerank: true`. Evidence-strength helpers: `is_weak(chunks, cfg)` / `next_k(k, cfg)` drive the agent re-search loop. | `weak_threshold = 0.35` calibrated: hit score 0.65 (ink-stain query), near-miss 0.26, unrelated −0.004. `k=10, k_step=10, k_max=40` set in config. Reranker adds cross-encoder precision at no index-build cost. | `Retriever` is lazy-loaded (VectorStore opened on first `retrieve()` call). | Stateless between queries; new query = new VectorStore.search() call. | Threshold documented in `embed.py`; changing it requires no rebuild. |
| **6 Agent** | Perceive query → decide tool → act → synthesize grounded cited answer; abstain if unsupported. | Retrieved chunks (scored), agent state, tool results. | Rule-based policy (`decide()`): evidence-gated re-search (widen k while weak; abstain at k_max). Synthesize via LLM (`llm/client.py`). | Fixed loop in `agent/agent.py`. Evidence gate: if `top_score < 0.35` widen k by k_step; abstain once k > k_max. Guardrails: autonomy, budget, prompt-injection defense (`agent/guardrails.py`). PII redacted before answer. | A fixed retrieve→answer path is not agentic. Re-search is the ONE required dynamic behaviour. `act-with-approval` autonomy mode in `configs/config.yaml`. | Cross-cutting seams wired in `wiring.py`. Structured traces in `logging_conf.py`. | `max_steps: 8, budget_usd: 0.05` in config. | Audit trail: every agent step and tool call logged to `traces/run.jsonl`. |
| **7 RL/RLVR** | (Bonus — not implemented in A2) | — | PPO / GRPO; `rl.train_policy: false` in config. | Tool-selection RL env (`rl/env.py`). RLVR reward on verifiable extraction accuracy. | Disabled: `rl.train_policy = false`. Infrastructure stubs exist. | Training loop in `rl/train_rl.py`. | Not deployed. | — |
| **8 Serving** | Serve grounded answers over HTTP + demo UI. | Pipeline index + agent. | FastAPI (`serve/api.py`), Gradio (`serve/ui.py`), Docker. | `/answer` endpoint calls `pipeline.answer(query, cfg)`. `/health` returns system status. | `serve.batch: true` in config. HF Spaces deployment target. | Dockerfile in repo root. | `deploy.target: hf-spaces`. | MLOps tracking via W&B (`mlops/tracking.py`). |
| **9 Eval** | Measure OCR quality, retrieval quality, answer quality; calibrate confidence. | `grading_kit/labels.jsonl` (40-page oracle), `grading_kit/tasks.jsonl` (QA pairs). | Metrics: OCR-F1, recall@k, groundedness, citation accuracy, ECE. Ablation: stage-toggle. | `eval/metrics.py` scores against held-out oracle. `eval/ablation.py` toggles each stage off and reports metric delta. Calibration: temperature scaling + ECE (primary NFR target ≤ 0.05). | Primary NFR: ECE ≤ 0.05 on task suite. Abstention triggered below calibrated confidence threshold. Stage ablation quantifies the contribution of each stage. | `eval_report.md` reports all numbers. `reports/figures/` for plots. | Eval runs via `scripts/run.sh`. | `mlops/registry.py` versions checkpoints + metrics. |
