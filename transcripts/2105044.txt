#### Open Issue 2: Unbounded Logits in Cross-Encoder Stub (`retrieval/rerank.py`)

**Observation in A2:**
The module `src/doc_agent/retrieval/rerank.py` is currently a pass-through stub.
While dense bi-encoder retrieval produces cosine scores bounded in [-1.0, 1.0],
introducing a cross-encoder model in A3 produces unnormalized logit outputs z in R.

**Root Cause:**
Raw cross-encoder logits z cannot be thresholded by a single fixed similarity constant.
Furthermore, standard sigmoid activation sigmoid(z) = 1 / (1 + e^-z) often produces
overconfident probabilities near 0 or 1, inflating the Expected Calibration Error (ECE).

**A3 Resolution Plan:**
1. **Implement Reranker:** Complete `retrieval/rerank.py` using `ms-marco-MiniLM-L-6-v2`.
2. **Platt / Temperature Scaling:** Apply temperature scaling to cross-encoder logits:
   p_hat = sigmoid(z / T)
   where temperature parameter T > 0 is optimized via negative log-likelihood on the
   validation set to minimize ECE.
3. **Unified Confidence Gate:** Establish a single calibrated probability scale p_hat in [0, 1]
   used consistently by both bi-encoder fallback and cross-encoder reranking stages.
---
